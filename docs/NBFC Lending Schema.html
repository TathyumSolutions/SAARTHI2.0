NBFC Lending Schema

The physical data model behind Saarthi's synthetic NBFC / lending-company demo database (demo_lending/db_lending.py): 13 tables covering the full loan lifecycle — origination, disbursement, EMI amortization, collections, payables, IRAC/NPA classification, credit-bureau pulls, and the disbursement ledger. All data is synthetic (Faker en_IN locale; PAN/Aadhaar/account numbers are valid-format, not real identifiers) and is provisioned into its own Postgres database, lending_demo_db, independent of Saarthi's own core databases.
