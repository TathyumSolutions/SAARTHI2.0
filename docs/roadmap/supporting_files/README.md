# Roadmap supporting files

Put any file that backs the roadmap deck here, for example:

- Excel (`.xlsx`, `.csv`): effort estimates, item trackers, budgets
- Word (`.docx`): specs, notes, meeting minutes
- Images (`.png`, `.jpg`, `.svg`): diagrams, screenshots, mock-ups
- SharePoint: add links to `sharepoint_links.md` (SharePoint files can't live in git, so we keep their URLs)
