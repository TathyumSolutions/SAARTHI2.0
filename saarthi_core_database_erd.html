Saarthi core database ERD

Drawn from the SQLAlchemy models in app/models/ of SAARTHI2.0 (commit 90b5bf9). The diagrams show only key and reference columns so they stay readable. Every column, with one sample value, is in the sample data section.

Core diagramData sources diagramWorkspace diagramSample data

Diagrams

Solid line: declared foreign key. Dashed line: logical reference with no constraint. Crow's foot: many side.

1. Core: tenants, users and access grants

Solid lines are declared foreign keys.

2. Data sources: what a grant points to

resource_mapping.resource_id points to the table named by resource_type (database, api, file, llm). No database constraint.

3. Workspace: chats, queries, feedback and LLM usage

All links are logical references by user_id, query_code or model_configuration_id. No database constraints.

One illustrative row per table. Values are made up but consistent across tables (user 7, company TATHYUM, query QUERY00001). They are not taken from a live database.
